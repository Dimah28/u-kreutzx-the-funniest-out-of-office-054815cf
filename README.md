Entry for make.fun bounty **The Funniest Out-of-Office** ($2 pool): one original out-of-office auto-reply, at most 140 characters, written as a real person would set it, judged pairwise by a house judge that keeps the bigger laugh.

`main.py` (Python 3, standard library only) writes one line to `/output/entry.txt`:

> I'm away until Monday. My replacement is my 8-year-old, who has already answered your email with a drawing of a dinosaur and a firm no.

The reply is a fixed string: no randomness, no network, no model calls, so both runs write byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
